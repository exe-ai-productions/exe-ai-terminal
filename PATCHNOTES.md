# Patch notes

## v1.3.9

The program is now called **Exe AI**, and it wears one header band like its
sibling programs: the wordmark, the menu beside it, then a status dot, a
memory pill and the settings gear at the right edge. The pill shows how much
of the machine's memory is in use, refreshed every couple of seconds.

**The catalogue in black-pearl.** The app icon, the Recommended plaque and
the Extended Workflow monogram leave the old lilac for the house black-pearl
— black on the light skins, pearl on the dark ones. Extended Workflow moves
to the very bottom of the module rail, where the thing the program is built
around gets the anchoring foot.

**Pictures stay where they are drawn.** A picture generated on this machine
now belongs to the chat it was started in, even when you switch away while it
draws — it no longer surfaces in whichever chat happens to be open. Drawing
with no chat open now creates one instead of refusing, so you can start by
making a picture without loading a chat model first. A generated picture no
longer travels back to the model as an image the next turn, which had been
leaving some local servers unable to answer. And the faint scrollbar that
could float over the picture window is gone.

Instructions for grilling a plan until it holds up ship with the program as
the **grill-me** skill.
